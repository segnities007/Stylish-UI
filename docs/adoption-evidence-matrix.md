# Stylish UI 採用証跡マトリクス

この文書は [`gafa-production-standard.md`](gafa-production-standard.md) の100点モデルを、
採用判断で確認できるマクロ項目とミクロ項目へ分解した証跡台帳です。調査日は
2026-08-20、対象はリポジトリ内で確認できる共通コード・JVM/Wasm CI・文書です。

## 判定方法

「実装がある」ことと「採用基準を満たした」ことを分けます。各ミクロ項目は、次の5点が
すべて揃ったときだけ完了とします。

1. 仕様 — 期待する状態・数値・プラットフォーム範囲が文書化されている。
2. コード — 公開APIまたは内部実装が仕様を実現している。
3. 証跡 — 自動テスト、スクリーンショット、ベンチマーク、または実機記録がある。
4. 文書 — 利用者が制約と採用方法を再現できる。
5. 回帰ゲート — CIまたはリリース手順で再発を検出できる。

したがって、`部分実証` は採用前の残課題がある状態、`実装あり・証跡不足` はコードの存在を
確認できても100点条件には数えない状態、`未整備` は根拠ファイルを確認できない状態です。
この表は点数を再計算するものではなく、採用時に何を追加確認すべきかを固定します。
